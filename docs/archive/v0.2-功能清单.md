## v0.2 顺手修掉的既有 bug

1. `TaskStore` 的 sqlite 连接不是线程安全的（`check_same_thread` 默认 True，
   多线程共用会抛 `ProgrammingError`）——WebUI 一来必炸
2. 多 AMS 单元时 tray id 互相覆盖（忽略了 `unit.id`）；外置料 `vt_tray` 完全没解析
3. `get_ams_trays()` 会顺手建 MQTT 连接——WebUI 每刷新一次就踢一次线
4. `PrinterLink` 只在回调里更新快照，而首个全量报文可能在注册回调之前就到了，
   导致网页打开是一片空白
5. 提交任务后接口返回的还是内存里的旧状态（`pending`），而文件其实已经传上去了
6. `var/` 下的路径是相对的，daemon 从别的工作目录启动会另建一套，且不报错
7. 鉴权写成「函数参数 + Depends」时 FastAPI 返回 422 而不是 401
8. Windows GBK 控制台输出 `⚠` 直接崩溃——而那正是「可能打错料」的警告符号
